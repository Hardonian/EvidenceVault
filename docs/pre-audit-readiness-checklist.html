Pre-Audit Readiness Checklist

Use this checklist before a SOC 2, ISO 27001, HIPAA, or enterprise security review. It is built for small teams that need operator truth, not compliance theatre.

1. Evidence inventory

  • List every control, policy, vendor artifact, and operating record the audit or customer review will request.
  • Give each evidence item a clear owner, renewal cadence, and current status.
  • Mark anything ownerless, expired, or older than one review cycle.

2. Retrieval path

  • Confirm where each file actually lives today: shared drive, ticketing system, HR system, cloud console export, or contract repository.
  • Remove duplicates and note the single canonical source for each artifact.
  • Check that the file can be exported again without relying on one person’s memory.

3. Review discipline

  • Set a weekly review rhythm for open gaps, upcoming expirations, and ownerless evidence.
  • Log what changed, what was renewed, and what remains blocked.
  • Keep the review output portable so you can show progress over time.

4. Export readiness

  • Verify you can export a clean evidence graph or summary without copy-pasting from six systems.
  • Make sure the export includes timestamps, owners, and unresolved gaps.
  • Test the export before the audit week, not during it.

5. Customer questionnaire readiness

  • Prepare a lightweight bundle for enterprise buyers who ask for proof of controls.
  • Map recurring questionnaire topics to existing evidence so the sales team is not rebuilding answers from scratch.
  • Keep a short narrative for what is complete, what is in progress, and what is intentionally out of scope.

6. Minimum operating bar

No ownerless evidence

If nobody owns it, it will break during the next audit cycle.

No silent expiry

Every expiring artifact needs a visible reminder and follow-up path.

No fake exports

Only promise the formats and workflows the product actually supports today.
