# Pilot Model

Purpose: Define implemented pilot semantics and conversion-relevant continuity logic.
Audience: Founders/operators.
Canonical status: Canonical pilot mechanics doc.

## Ritual State Semantics
Pilot state tracks cadence week, expected next action, and continuity readiness based on completed reviews.

## Week Progression
- Week progression is review-count dependent.
- Cadence warnings appear when reviews are missed.

## Conversion Strategy (Implemented)
Use week-over-week deterministic exports (narratives + review comparison) to demonstrate continuity discipline.

## Continuity Dependence
No continuity story exists without persisted historical reviews.

## Explicit Limitations
- No predictive scoring engine.
- No automated advisory intelligence.
- Output quality depends on real operator usage.
