# Activation Model

Milestones are deterministic and timestamped per tenant:
1. first evidence created
2. first file uploaded
3. first reminder run
4. first proofpack generated
5. first operational review
6. second weekly review

Activation completion is `completed/6 * 100`.
Pilot maturity stages:
- exploring
- activated (evidence + upload)
- operational (proofpack + review)
- recurring (second weekly review)
- expansion-ready (healthy cadence, multiple owners, proofpack history, sustained streak)
