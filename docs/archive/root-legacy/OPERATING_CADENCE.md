# EvidenceVault Operating Cadence

- Weekly: run operational review in `/app`, generate review snapshot JSON, resolve owner gaps, stale evidence, and expirations.
- Monthly: generate at least one proofpack export and retain history for audit continuity.
- Quarterly: audit entire evidence set for stale/archived records and ownership coverage.

EvidenceVault retention loop: review score -> owner accountability -> updates -> proofpack history.

Limitations: no scheduler/automations; actions are operator-driven.
